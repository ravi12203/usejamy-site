How a check works

There is no guessing in it. JAMY runs the real programs and compares what comes out.

  1. Write down the requestWhat should change, and what must not. JAMY locks it before anything runs.
  2. Run both versionsThe old and the new program, on the same test files, on the PC.
  3. Compare every byteEvery record of every output file, old against new.
  4. A second person approvesThey get an evidence pack, not a ticket. The person who asked can’t approve.

It tells you when it can’t be sure

Every check ends in one of three plain answers, with the reason.

Ran and checked

Both versions ran, and the outputs differ only where the request said they would.

Read from the code

This part couldn’t be run, so the answer comes from reading the code. JAMY shows you the lines.

Not proven

JAMY couldn’t show the change is safe, and it says exactly why.
